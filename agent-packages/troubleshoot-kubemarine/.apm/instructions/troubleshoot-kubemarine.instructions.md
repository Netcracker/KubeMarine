---
description: Diagnostic playbook for KubeMarine procedure failures and Kubernetes operational issues.
applyTo: "**/*"
---

When diagnosing a KubeMarine problem — a failed install/upgrade/add_node/remove_node procedure, a KME error code,
an etcd issue, a Calico or CNI networking failure, a node NotReady status, a CoreDNS resolution failure, an
ingress or webhook error, or any Kubernetes operational issue in a KubeMarine-managed cluster — apply the
`troubleshoot-kubemarine` skill.
